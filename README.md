# Design Patterns in Java

This repository contains clean implementations of common design patterns in Java.

---

## 📁 Categories

### 🟢 Creational Patterns
Object creation patterns such as Singleton, Factory, Builder, and Prototype.

- [Singleton](./src/creational/singleton)
- [Factory](./src/creational/factory)
- [Builder](./src/creational/builder)
- [Prototype](./src/creational/prototype)

---

### 🔵 Structural Patterns
Patterns that deal with class and object composition.

- [Adapter](./src/structural/adapter)
- [Proxy](./src/structural/proxy)

---

### 🟡 Behavioral Patterns
Patterns focused on communication between objects.

- [Chain of Responsibility](./src/behavioral/chainofresponsibility)
- [Command](./src/behavioral/command)
- [Mediator](./src/behavioral/mediator)
- [Memento](./src/behavioral/memento)
- [Observer](./src/behavioral/observer)
- [State](./src/behavioral/state)
- [Strategy](./src/behavioral/strategy)
---

## 🎯 Goal

To learn design patterns through minimal, readable implementations rather than over-engineered examples.
